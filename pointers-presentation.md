Как пользоваться
================

```bash

```

* Слайды-ответы: код — обычные C-программы в `pointers/*.c` (во всю ширину слайда)
* Код не исполняется: ожидаемый вывод указан комментарием рядом с `printf`

==========

Задача 5. const и указатели
===========================

```c
int a = 1, b = 2;
const int *p1 = &a;
int *const p2 = &a;
const int *const p3 = &a;

*p1 = 5;  p1 = &b;   // (1) (2)
*p2 = 5;  p2 = &b;   // (3) (4)
*p3 = 5;  p3 = &b;   // (5) (6)
```

Для каждой из шести операций определите, скомпилируется ли она, и объясните почему.

<!-- end_slide -->

Задача 5. Ответ
===============

| Строка | Компилируется? | Причина                         |
|--------|----------------|---------------------------------|
| (1)    | нет            | данные через `p1` менять нельзя |
| (2)    | да             | сам указатель менять можно      |
| (3)    | да             | данные менять можно             |
| (4)    | нет            | `p2` константный указатель      |
| (5)    | нет            | данные константны               |
| (6)    | нет            | указатель константный           |

Читайте объявление **справа налево**.

Задача 10. Адресная арифметика
==============================

```c
int a[5] = {10, 20, 30, 40, 50};
int *p = a;
p += 3;
printf("%d\n", *p);
printf("%td\n", p - a);
printf("%td\n", (char *)p - (char *)a);
```

* **а)** Что выведет программа?
* **б)** Какой адрес у `p`, если `a` лежит по `0x1000`?
* **в)** Что изменится для массива `double`?
* **г)** Почему нельзя сложить два указателя?

<!-- end_slide -->

Задача 10. Ответ
================

```file
path: pointers/task10.c
language: c
```

* `p += 3` сдвигает на `3 * sizeof(int)` байт, поэтому `0x100C`
* Для `double` сдвиг 24 байта, а разность указателей по-прежнему 3

================

```file
path: pointers/task13.c
language: c
start_line: 3
end_line: 5
```
