Задача 1. Hello, world
======================

Напишите программу, которая печатает `Hello, world!`.

Заодно разберём, как программа собирается компилятором и запускается.

<!-- end_slide -->

Задача 1. Ответ
===============

```file
path: task01.c
language: c
```

Сборка и запуск через `gcc`:

```bash +exec
gcc task01.c -o /tmp/task01
/tmp/task01
```

* `gcc` — компилятор
* `-o /tmp/task01` задаёт имя собранного файла
* вторая строка запускает готовую программу

<!-- end_slide -->

Задача 5. Аргументы и `scanf`
=============================

Напишите программу, которая берёт число из `argv`, а если аргументов нет —
читает его через `scanf`.

* `./task05 42` → `n = 42`
* `./task05` без аргументов → число запрашивается на вводе

<!-- end_slide -->

Задача 5. Ответ
===============

```file
path: task05.c
language: c
```

Число передаём аргументом:

```bash +exec
gcc task05.c -o /tmp/task05
/tmp/task05 42
```
