Задача 1. Структура: значение или указатель
===========================================

Дана структура и две функции:

```c

void set_by_value(item_t m);
void set_by_pointer(item_t *m);
```

* **б)** Почему вторая работает, а первая нет?

Задача 2. Возврат массива из функции
====================================

Функция должна вернуть массив нечётных чисел из `src`:

```c
int get_odd(const int *src, size_t n, int *dst) {
    size_t len = ...;
    ...
    dst = malloc(len * sizeof *dst);
    ...
    return (int)len;
}
```

* **а)** Почему после вызова `dst` у вызывающего остаётся прежним?
* **б)** Как исправить: вернуть указатель или взять `int **dst`?
* **в)** Кто и когда освобождает эту память?

<!-- end_slide -->

Задача 2. Ответ
===============

```file
path: pointers-alt/task02.c
language: c
start_line: 4
end_line: 24
```

`dst` — тоже **копия** указателя: `malloc` меняет локальную переменную, а не переменную вызывающего. Нужен `int **dst`, и тогда адрес записывается через `*dst = out`.

Вернуть указатель напрямую тоже можно, но длину всё равно придётся отдать наружу — через `size_t *n_dst`. Освобождает вызывающий: `free(odd)`. Вывод: `4: 1 3 5 7`.

Задача 3. Висячий указатель
===========================

```c
int *get_squares(size_t n) {
    int a[5];
    for (size_t i = 0; i < n; i++)
        a[i] = (int)(i * i);
    return a;
}
```

* **а)** Что не так с `return a`?
* **б)** Почему программа может «случайно работать»?
* **в)** Назовите три способа вернуть массив наружу

<!-- end_slide -->

Задача 3. Ответ
===============

```file
path: pointers-alt/task03.c
language: c
```

`a` живёт в кадре функции; после `return` кадр исчезает, и указатель висит. Данные ещё лежат в стеке, пока их не перезапишет следующий вызов, поэтому «иногда работает».

Три способа: буфер от вызывающего (`fill_squares(buf, 5)`), `static`-массив, `malloc` + `free`. Первый не требует освобождения и показан выше.

Задача 5. const и указатели
===========================

```c
int a[3] = {1, 2, 3};
const int b[3] = {4, 5, 6};

int *p1 = a;
const int *p2 = a;
const int *p3 = b;
int *p4 = b;
p2[0] = 9;
b[0] = 9;
```

* **а)** Какие строки не компилируются?
* **б)** Почему `const` можно добавить, но нельзя убрать?
* **в)** Почему `a = p1` тоже ошибка?

<!-- end_slide -->

Задача 5. Ответ
===============

```file
path: pointers-alt/task05.c
language: c
```

`int *p4 = b`, `p2[0] = 9` и `b[0] = 9` — ошибки: `const` можно только **добавлять**. Иначе через `p4` можно было бы изменить `b`.

После затухания массив ведёт себя как `int *const`: элементы менять можно, а `a = p1` — нет.
