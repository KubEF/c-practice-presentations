Задача 1. Сумма и максимум
===========================

Реализуйте два обхода массива:

```c
int array_sum(const int *a, size_t n);
int array_max(const int *a, size_t n);
```

* Диапазон `[a, a + n)`, длину передают отдельно
* `array_max` при `n == 0`: договоритесь, что делать, и защитите это
* Указатели `const` — читать массив, не менять

Задача 3. Бинарный поиск
========================

Напишите `int binary_search(const int *a, size_t n, int key)`: возвращает индекс найденного элемента или `-1`.

* Массив **отсортирован** по возрастанию
* Сложность `O(log n)`: без рекурсии
* Диапазон `[lo, hi)` — полуинтервал, как в `sum` из прошлой колоды

<!-- end_slide -->

Задача 3. Ответ
===============

```file
path: task03.c
language: c
start_line: 3
end_line: 18
```

`hi = mid`, а не `mid - 1`: полуинтервал сам по себе уже исключает проверенный элемент. `lo + (hi - lo) / 2` не переполняется, в отличие от `(lo + hi) / 2`.

<!-- end_slide -->

Задача 4. Уникальные элементы
=============================

Напишите `size_t uniq(int *a, size_t n)`: убирает дубликаты **на месте** и возвращает новую длину.

* Массив **отсортирован**: одинаковые значения лежат подряд
* `O(n)`, дополнительная память — одна переменная
* Хвост массива после новой длины не обнулять

<!-- end_slide -->

Задача 4. Ответ
===============

end_line: 15
