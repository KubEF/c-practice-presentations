Задача 10. Адресная арифметика
==============================

```c
int a[5] = {10, 20, 30, 40, 50};
int *p = a;
p += 3;
printf("%d\n", *p);
printf("%td\n", p - a);
printf("%td\n", (char *)p - (char *)a);
```

* **а)** Что выведет программа?
* **б)** Какой адрес у `p`, если `a` лежит по `0x1000`?
* **в)** Что изменится для массива `double`?
* **г)** Почему нельзя сложить два указателя?

<!-- end_slide -->

Задача 10. Ответ
================

```file 
path: task10.c
language: c
```

* `p += 3` сдвигает на `3 * sizeof(int)` байт, поэтому `0x100C`
* Для `double` сдвиг 24 байта, а разность указателей по-прежнему 3

Задача 11. Указатели и массивы
==============================

```c
char str[80] = "abcdefgh";
char *p1 = str;
```

* **а)** Выведите пятый символ двумя способами
* **б)** Чему равны `sizeof str` и `sizeof p1`?

<!-- end_slide -->

Задача 11. Ответ
================

```file
path: task11.c
language: c
```

`str[4]` и `*(p1 + 4)` — одно и то же: `a[i]` по определению это `*(a + i)`.

`sizeof str` это размер всего массива (80), а `sizeof p1` — размер указателя (8): сам указатель не хранит длину массива.
